1. 概述

HTMLayout 的 CSS 支持以 CSS 2.1 为基准，同时支持部分 CSS3 属性和选择符，以及大量独有扩展属性。

与标准 CSS3 的主要差异：

  • 不支持 flexbox，用 flow + %% / * 替代
  • 不支持 linear-gradient()，用四角颜色 background-color: A B C D 替代
  • 不支持 transition 动画语法，但有自己的 transition 扩展
  • 扩展了 flow、behavior、foreground 等独有属性
  • 支持 CSSS! 脚本，可在 CSS 中写简单逻辑

3. 单位系统

单位说明示例
px像素width: 100px;
%百分比（基于父元素）width: 80%;
dip设备无关像素（推荐）height: 32dip;
%%剩余空间比例分配width: 50%%;
*均分剩余空间height: *;
em相对字体大小font-size: 1.2em;
核心概念：%% 和 * 是 HTMLayout 弹性布局的关键。
  • 50%% 表示占用剩余空间的 50%
  • * 表示均分剩余空间（多个 * 等分）
  • margin 和 padding 也可使用 %% 单位
/* 两个子元素各占 50% 剩余空间 */
#a { width: 50%%; }
#b { width: 50%%; }

/* 三个子元素均分剩余空间 */
.a { width: *; }
.b { width: *; }
.c { width: *; }

4. 布局属性

flow — 容器内布局方向 扩展

替代 CSS3 flexbox 的核心属性，控制子元素的排列方式。

值说明
vertical子元素垂直排列（类似 flex-direction: column）
horizontal子元素水平排列（类似 flex-direction: row）
v-flow垂直流式布局（超出则换行）
h-flow水平流式布局（超出则换行）
/* 垂直布局，子元素从上到下排列 */
#app {
    size: *;
    flow: vertical;
    border-spacing: 10dip;  /* 子元素间距 */
}

/* 水平布局，子元素从左到右排列 */
.toolbar {
    flow: horizontal;
    border-spacing: 8dip;
    vertical-align: middle;
}

对齐属性

属性说明可选值
horizontal-align水平对齐left / center / right
vertical-align垂直对齐top / middle / bottom
text-align文本对齐left / center / right
/* 按钮内文字垂直水平居中 */
.btn {
    flow: horizontal;
    horizontal-align: center;
    vertical-align: middle;
    text-align: center;
    behavior: clickable;
}

border-spacing — 子元素间距

在 flow: horizontal 或 flow: vertical 布局中，控制子元素之间的间距。

.card-list {
    flow: vertical;
    border-spacing: 15dip;  /* 子元素间垂直间距 15dip */
}

size — 简写

size 是 width 和 height 的简写。

#app { size: *; }         /* 等价于 width:*; height:*; */
.spacer { size: *; }      /* 弹性占位符 */

position

支持 static、relative、absolute、fixed，用法同 CSS 2.1。

.modal-overlay {
    position: fixed;
    top: 0; left: 0; right: 0; bottom: 0;
}
.modal-close {
    position: absolute;
    right: 12dip;
    top: 14dip;
}

6. 背景与前景

渐变色背景 扩展

HTMLayout 不支持 CSS3 的 linear-gradient()，但支持四角颜色渐变。

注意：虽然写 linear-gradient(135deg, #ff6b6b, #ff8e53) 不会报错，但引擎会忽略它，退化为纯色或无背景。必须使用以下语法： 
/* 格式：上左颜色 上右颜色 下右颜色 下左颜色 */
background-color: red yellow blue yellow;

/* 实际示例：标题栏渐变 */
#title-bar-wrap {
    background-color: #4ecdc4 #44a08d #282b32 #1a1a2e;
}

背景图模式 — background-repeat

模式说明
no-repeat不缩放不重复，配合 position 定位
repeat重复铺满（含边框区域）
repeat-x横向重复
repeat-y垂直重复
expand九宫格切图，四角保持原样
stretch拉伸适应节点内部空间

九宫格切片贴图（expand）

将图片切为 3x3 九块，四角保持原样不拉伸，中间块默认平铺或拉伸。

background: url(bg.png) expand;
/* 切片位置：上 右 下 左 */
background-position: 30px 30px 30px 30px;
/* 指定拉伸的中间块 */
background-stretch: stretch-top stretch-bottom stretch-left stretch-right stretch-middle;
/* 不指定 stretch 的中间块默认平铺 */

stretch 模式 — 保持长宽比

background: url(image.png) stretch keep-ratio;

精确定位属性 扩展

/* 图片相对 padding box 的偏移 */
background-position-left: 10px;     /* 左上角左侧偏移 */
background-position-top: 10px;       /* 左上角顶部偏移 */
background-position-right: 10px;    /* 右下角右侧偏移 */
background-position-bottom: 10px;   /* 右下角底部偏移 */

/* 简写：横坐标 纵坐标 */
background-position: 50px 50px;

/* expand 模式简写：上 右 下 左 */
background-position: 6px 6px 6px 6px;
坐标含义：这里的坐标指图片左上角相对于节点 padding box 的偏移，不是图片本身的坐标。正数表示向右/向下移动，负数表示向左/向上移动。

前景样式（foreground） 扩展

前景样式与背景语法完全相同，只需将 background 替换为 foreground。前景覆盖在背景和内容之上。

foreground: red url(fg.png) no-repeat 50% 50%;
foreground-color: ...;
foreground-image: ...;
foreground-repeat: ...;
foreground-position: ...;
foreground-stretch: ...;
层级关系：父元素 A 的前景图 > 子元素 B 的背景图 > 父元素 A 的背景图。前景图常用于按钮图标，背景图用于按钮底纹。

Data URI 支持

background-image: url(data:image/png;base64,iVBORw0KGgo...);

7. 图像变换效果

HTMLayout 支持对前景和背景图像的多种变换效果。

变换函数说明参数
opacity(n)透明度0.0 ~ 1.0
flip-x()左右翻转无
flip-y()上下翻转无
colorize(#color)颜色滤镜颜色值
contrast-brightness-gamma(c, b, g)对比度/亮度/gamma各值中间值 0.5
color-schema(c1, c2, ...)灰度色插值变换多个颜色
/* 透明度 */
background-image-transformation: opacity(0.5);

/* 颜色滤镜 — 常用于禁用状态 */
background-image-transformation: colorize(#FFCC00);

/* 对比度亮度调整 — 常用于 hover 效果 */
img:hover {
    foreground-image-transformation: contrast-brightness-gamma(0.5, 0.3, 1.2);
}

/* 灰度色插值 */
background-image-transformation: color-schema(red, yellow, blue);

9. 动画效果

transition — 状态渐变 扩展

HTMLayout 的 transition 与 CSS3 不同，是状态切换时的渐变效果。

/* blend 渐变切换 — 适合按钮，有性能问题不建议大量使用 */
transition: blend;

/* 自定义属性变换 */
transition: width(linear, 400ms) height(linear, 400ms);
transition: width(back-in, 0.5s) background-color(back-in, 0.5s, 0.5s);

动画速率函数

函数说明
linear线性变化
back-in回弹进入
back-out回弹退出
blend混合渐变

CSSS! 脚本动画

.notification.show {
    display: block;
    assigned!: self::opacity = 0.01, self.start-animation();
    animation-step!: self::opacity < 1.0
        ? ( self::opacity = self::opacity + 0.01, return 10 )
        # ( self.fade = "", return cancel );
}

通过 CSS 为元素附加预定义交互行为，是 HTMLayout 的核心扩展。

常用 behavior

行为说明属性状态

clickable可点击（不获得焦点）—:hover :active :disabled
check复选框checked, mixed:hover :active :focus :disabled :checked
radio单选框name, value:hover :active :focus :disabled :checked

select下拉列表size, multipleoption:current
menu菜单容器—:current

popup-menu弹出菜单menu, align-popup—

path路径缩略显示——

edit 的 filter 属性 — 输入限制

<!-- 只允许数字 -->
<input filter="0~9" />

<!-- 允许字母、数字、. 和 @ -->
<input filter=".@0~9a~zA~Z" />

<!-- 允许除 . , - 外的任意字符 -->
<input filter="^.,-" />

edit 的 novalue 属性 — 占位提示

<input novalue="请输入端口" />
<!-- 可通过 :empty 伪类修改占位文本样式 -->
input:empty { color: #555; }

实际使用示例

/* 可点击的卡片 */
.action-card {
    behavior: clickable;
}
.action-card:hover {
    background: #32363f;
}

/* 模态对话框 */
.modal {
    behavior: light-box-dialog;
}

/* 超链接 */
a { behavior: hyperlink; }
a:hover { color: #4ecdc4; }

/* 复选框 */
a[type="check"] {
    behavior: check;
    display: inline-block;
    cursor: pointer;
}

12. 滚动条样式

HTMLayout 支持通过 @set 规则自定义滚动条外观。

@set small-v-scrollbar {
    .prev { border: 1px solid #1e2130; }
    .next { border: 1px solid #1e2130; }
    .slider {
        background-color: #2a2e42;
        min-height: 32px;
    }
    .next:disabled, .slider:disabled, .prev:disabled {
        height: 0;
        border: none;
        foreground-image: none;
    }
    .next:hover, .slider:hover, .prev:hover {
        background-color: #6366f1;
    }
    .base { width: 2px; }
}

/* 应用到元素 */
pre#log {
    vertical-scrollbar: small-v-scrollbar;
    overflow: auto;
}

滚动条子元素

子元素说明
.base滚动条背景轨道
.slider可拖动的滑块
.prev上/左箭头按钮
.next下/右箭头按钮
应用属性说明
vertical-scrollbar垂直滚动条
horizontal-scrollbar水平滚动条

13. CSSS! 脚本

HTMLayout 内置的简单脚本语言，可在 CSS 中使用，以 ! 结尾的事件属性触发。

事件属性

属性触发时机
assigned!样式被应用到元素时
click!元素被点击时
animation-step!动画每一步
value-changed!值发生变化时

语法要点

  • self — 当前元素
  • self::property — 访问 CSS 属性
  • return value — 返回值（动画延迟毫秒数等）
  • condition ? (expr) # (expr) — 三元表达式（用 # 而非 :）
  • , — 语句分隔符

示例 — 淡入动画

.notification.show {
    display: block;
    assigned!: self::opacity = 0.01, self.start-animation();
    animation-step!: self::opacity < 1.0
        ? ( self::opacity = self::opacity + 0.01, return 10 )
        # ( self.fade = "", return cancel );
}

14. CSS 常量与变量

@const — 常量定义 扩展

@const BASE_COLOR: #22c55e;

h1.title b:nth-child(1) { color: tint(@BASE_COLOR, -0.5, -0.5); }
h1.title b:nth-child(2) { color: tint(@BASE_COLOR, -0.25, -0.5); }
h1.title b:nth-child(3) { color: tint(@BASE_COLOR, 0.0, -0.5); }

tint() — 颜色调色函数 扩展

/* tint(基础颜色, 亮度调整, 饱和度调整) */
/* 亮度: -1.0 ~ 1.0, 0 为不变 */
/* 饱和度: -1.0 ~ 1.0, 0 为不变 */
color: tint(@BASE_COLOR, 0.5, -0.5);

15. 注意事项与踩坑

1. 不支持 CSS3 linear-gradient()
渐变只能用四角颜色 background-color: A B C D。写 linear-gradient 不会报错但会被忽略。
2. 不支持 flexbox
用 flow: vertical/horizontal + %% / * 单位实现弹性布局。
3. @font-face 必须放在 <style> 最前面
否则字体可能不生效。@font-face 之后才能写其他规则。
4. SetHtml 动态插入的 HTML 不应含多余空白
换行和制表符会被当作文本节点，影响表格行间距等布局。动态生成的 HTML 应写成紧凑单行。
5. SetText("") 会 panic（gohl bug）
空字符串需传 " "（一个空格）占位。
6. <input> 值读取用 GetValue()
ValueAsString() 对 <input> 元素无效，始终返回空字符串。
7. 推荐使用 dip 单位
dip 是设备无关像素，能自动适应 DPI 缩放。避免在高 DPI 屏幕上布局错乱。
8. flow: vertical + height: * 实现等分
多个子元素都设 height: * 时会均分父元素剩余空间，类似 flexbox 的 flex: 1。
9. border-spacing 控制子元素间距
在 flow: horizontal 或 flow: vertical 布局中，border-spacing 是控制子元素间距的推荐方式。
10. overflow: auto + vertical-scrollbar 实现自定义滚动条
先设 overflow: auto 启用滚动，再用 vertical-scrollbar: 名称 引用 @set 定义的滚动条样式。
